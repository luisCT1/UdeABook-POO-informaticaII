# UdeABook

Proyecto del Desafio II de Informatica II (UdeA) 2026-2.
Red social por consola hecha en C++ con POO, sin herencia y con memoria dinamica.

## Integrantes
- Luis Miguel Cohen Teheran
- David Aguirre

## Que hace
- Cargar datos desde archivos .txt
- Iniciar sesion y ver 3 fotos de amigos
- Solicitudes de amistad y sugerencias
- Ver perfil y albumes
- Enviar y buscar mensajes
- Mostrar iteraciones y memoria despues de cada funcionalidad

## Como correrlo
1. Abrir `Desafio_2/Desafio_2.pro` en Qt Creator
2. Compilar y ejecutar (por defecto carga `datos/mediano`)
3. Para otra base, en `main.cpp` cambia `"datos/mediano"` por `"datos/pequenio"` o `"datos/grande"`
